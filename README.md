# TARAJAL

A top-down beach defense game set at Playa del Tarajal (Ceuta, Spain). Built with [Three.js](https://threejs.org/) and Vite.

Waves of people come ashore on boats, rafts, and by swimming. Stop them before they reach the city gate. Fight with your fists. Invaders mostly run for the city, but turn aggressive when attacked or when they see their friends hit.

You lose if too many get through, or if you die.

## Play

```bash
npm install
npm run dev
```

- **WASD** — move (you face the way you move)
- **Shift** — run (drains stamina)
- **Click** or **Space** — punch forward
- **Esc** — pause

## Build

```bash
npm run build
npm run preview
```
